# Bamboo Website 🎋

A modern e-commerce website built with [Next.js](https://nextjs.org), featuring Sanity CMS integration and a clean, responsive design.

## 👤 Author

**NishantSingh2964** — [GitHub](https://github.com/NishantSingh2964)

## 🚀 Getting Started

First, run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠 Tech Stack

- **Framework**: Next.js (App Router)
- **CMS**: Sanity.io
- **Styling**: CSS / Tailwind CSS
- **Package Manager**: pnpm
- **Deployment**: Vercel

## 📁 Project Structure

- `app/` — Next.js App Router pages and layouts
- `components/` — Reusable UI components
- `sanity/` — Sanity CMS schema and configuration
- `public/` — Static assets

## 🌐 Deploy on Vercel

The easiest way to deploy this app is via the [Vercel Platform](https://vercel.com/new).

Check out the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
